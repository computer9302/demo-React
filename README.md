# Demo React - 회원·게시판 프로젝트

Spring Boot + MyBatis + React 기반 게시판 프로젝트입니다.

## 기술 스택
- Java 17, Spring Boot, MyBatis
- MySQL
- React, JavaScript, React Router
- Vite

## 주요 기능
- 회원 로그인 / 회원가입 / 로그아웃 (Bcrypt, 세션 기반 인증)
- 게시글 CRUD, 페이징, 검색
- 게시글 상세 및 댓글 (1:N)·등록·삭제
- React SPA와 Spring Boot REST API 연동 (CORS, 세션 쿠기)
