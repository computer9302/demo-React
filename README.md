# Demo - 회원·게시판 프로젝트

Spring Boot + MyBatis + JSP 기반 게시판 프로젝트입니다.

## 기술 스택
- Java 17, Spring Boot, MyBatis
- MySQL
- HTML, JSP, JSTL, JavaScript (AJAX)
- Bootstrap 5

## 주요 기능
- 회원 로그인 / 회원가입 (BCrypt, 아이디 중복확인 AJAX)
- 게시글 CRUD, 페이징, 검색
- 댓글 (1:N), AJAX 등록·삭제
- 세션 기반 로그인
